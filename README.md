# 電動車經銷商報價系統原型

這是一個從零建立的網頁版報價程式原型，可直接打開 `index.html` 使用。

## 目前功能

- 產品類別：全部商品、電動車輛、電池系統、維修零件、配件精品
- 產品圖與規格顯示
- 搜尋產品
- 加入下單專區
- 調整數量、移除品項、清空報價
- 經銷商等級折扣
- 小計、折扣、5% 營業稅、報價總額
- 經銷商資料、聯絡人、報價單號、交貨方式
- 備註欄
- 列印報價單

## 修改產品

產品資料在 `app.js` 最上方的 `products` 陣列。

每個產品可以修改：

- `name`：產品名稱
- `category`：產品類別，對應 `vehicle`、`battery`、`parts`、`accessory`
- `tag`：畫面上的類別標籤
- `spec`：產品規格說明
- `price`：單價
- `image`：目前的示意圖類型

之後如果要換成真實產品照片，可以把產品圖區塊改成圖片網址或本機圖片路徑。
